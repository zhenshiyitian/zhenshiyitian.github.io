# Zhenshiyi Tian — academic homepage

This repository contains the static source for [Zhenshiyi Tian's academic homepage](https://zhenshiyitian.github.io/zhenshiyi.tian.github.io/).

## Local preview

Run `node preview.mjs` in this repository, then open http://127.0.0.1:8000. Press `Ctrl+C` to stop the private local server.

## GitHub Pages

In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/(root)**. GitHub Pages will publish this repository at https://zhenshiyitian.github.io/zhenshiyi.tian.github.io/. The `.nojekyll` file makes GitHub serve the static files directly.
